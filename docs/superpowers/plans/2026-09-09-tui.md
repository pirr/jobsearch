# Interactive Terminal UI (`jobsearch tui`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the terminal-scrollback-limited `jobsearch show`/`mark`/`mark-duplicate`/`update-description` workflow with an interactive, keyset-paginated Textual TUI (`jobsearch tui`) that removes the display limit and lets every status/duplicate/description action happen in place.

**Architecture:** A new `src/jobsearch/tui/` package (Textual `App` + two secondary screens + one modal) drives the existing `Store` exactly the way `cli/main.py` already does -- no parallel data path. Pagination is keyset (seek), not `OFFSET`, so marking a vacancy dismissed mid-browse never duplicates or skips rows on the next page. Two small pieces of CLI logic (`$EDITOR` invocation, LLM error hints) move into shared modules so the CLI and the TUI use one implementation each.

**Tech Stack:** Python 3.11+, Textual (`textual>=8.2`), existing `rich`/`typer`/`sqlite3`/`pytest`+`pytest-asyncio` (already configured with `asyncio_mode = auto`, which Textual's `App.run_test()` pilot tests use directly).

**Spec:** `docs/superpowers/specs/2026-09-09-tui-design.md`

## Global Constraints

- `textual>=8.2` (current stable at spec time) -- added to `pyproject.toml`'s core `dependencies`, not optional.
- No `OFFSET` pagination anywhere -- all paginated queries use keyset (seek) predicates, per the spec's "Pagination" section.
- The TUI never calls `Store.upsert_vacancies` or otherwise duplicates ingest/business logic -- it only reads/writes through existing and newly-added `Store` methods, matching `cli/main.py`'s module docstring ("Every command reads or writes SQLite and nothing else").
- `sort_by`/`sort_dir` values are validated against an explicit allowlist before being interpolated into SQL -- never built from raw, unvalidated text.
- Existing CLI commands (`show`, `mark`, `mark-duplicate`, `update-description`, etc.) keep working unchanged for scripting.
- Every new Textual widget interaction is tested via `App.run_test()`'s `Pilot` (`pilot.press(...)`, `pilot.pause()`), consistent with the project's existing 100%-offline test suite (no real terminal, no network, no LLM calls -- `FakeLLM` stands in).

```python
def test_ranked_page_keyset_is_stable_when_a_row_leaves_the_view_mid_browse(store, profile):

    # fetching page 1 and page 2, an OFFSET-based query would shift v3 into
    # page 1's old slot and duplicate it into page 2. Keyset pagination
    # anchors each page on the last row actually seen, not a row count, so
    # this can't happen.
    h = profile.hash()
    v1 = make_vacancy(source_id="1", title="A")
    v2 = make_vacancy(source_id="2", title="B")
    v3 = make_vacancy(source_id="3", title="C")

    store.save_rating(v2.id, h, "f", score=80)
```

```python
    def ranked_page(
        self,
        profile_hash: str,
        threshold: int,
        *,
        only_status: str | None = None,
        after: tuple[int, str] | None = None,
        page_size: int = 50,
    ) -> list[sqlite3.Row]:
        """Keyset-paginated vacancy list for the TUI, score DESC.

        Ordered by (score, id) with a seek predicate on `after` -- never
        OFFSET, which silently duplicates or skips rows across pages when a
        status change mid-browse shrinks the filtered result set out from
        under a numeric offset. `after` is the (row["_sort_key"], row["id"])
        of the last row already loaded by the caller; pass None for the
        first page. Named (`:name`) parameters, not positional `?`, because
        the WHERE clause is assembled dynamically from several optional
        pieces -- positional params would be fragile to reorder here.
        """
        params: dict[str, object] = {
            "profile_hash": profile_hash,
            "threshold": threshold,
            "page_size": page_size,
        }
        if only_status:
            status_clause = "COALESCE(s.status,'new') = :status"
            params["status"] = only_status
        else:
            status_clause = "COALESCE(s.status,'new') NOT IN ('dismissed', 'closed')"

        where = [
            "r.profile_hash = :profile_hash",
            "r.failed = 0",
            "r.score >= :threshold",
            "v.id NOT IN (SELECT vacancy_id FROM vacancy_duplicates)",
            status_clause,
        ]
        if after is not None:
            after_value, after_id = after
            where.append(
                "(r.score < :after_value OR (r.score = :after_value AND v.id > :after_id))"
            )
            params["after_value"] = after_value
            params["after_id"] = after_id

        sql = f"""
            SELECT v.*, r.score, r.verdict, r.matched_skills, r.missing_skills,
                   r.hard_blockers, r.model, r.evidence,
                   COALESCE(s.status,'new') AS status,
                   r.score AS _sort_key
            FROM ratings r
            JOIN vacancies v ON v.id = r.vacancy_id
            LEFT JOIN vacancy_status s ON s.vacancy_id = v.id
            WHERE {" AND ".join(where)}
            ORDER BY r.score DESC, v.id ASC
            LIMIT :page_size
        """
        return list(self.conn.execute(sql, params))
```

Add these module-level constants in `src/jobsearch/vacancies/store.py`, near `VALID_STATUSES`:

```python
_SORT_COLUMNS = {
    "score": "r.score",
    "posted_at": "v.posted_at",
    "company": "v.company",
    "title": "v.title",
}
# posted_at is the only nullable sort column here (r.score is guaranteed
# non-null by the r.score >= :threshold filter below -- NULL >= number is
# NULL, i.e. excluded; company/title are NOT NULL in the schema). COALESCE
# it to a sentinel that always sorts after every real value in either
# direction, so unposted-date rows land at the end of the list regardless
# of sort_dir instead of SQLite's default rule (NULLs sort first in ASC),
# which would scatter them to the front.
_NULL_SENTINELS = {"desc": "", "asc": "9999-12-31T23:59:59+00:00"}
```

Replace the `ranked_page` method body from Task 1 with:

```python
    def ranked_page(
        self,
        profile_hash: str,
        threshold: int,
        *,
        only_status: str | None = None,
        sort_by: str = "score",
        sort_dir: str = "desc",
        after: tuple[object, str] | None = None,
        page_size: int = 50,
    ) -> list[sqlite3.Row]:
        """Keyset-paginated vacancy list for the TUI.

        Ordered by (sort_expr, id) with a seek predicate on `after` -- never
        OFFSET, which silently duplicates or skips rows across pages when a
        status change mid-browse shrinks the filtered result set out from
        under a numeric offset. `after` is the (row["_sort_key"], row["id"])
        of the last row already loaded by the caller; pass None for the
        first page. Each row carries its own `_sort_key` so the caller never
        has to reimplement the COALESCE-sentinel logic to build the next
        cursor. Named (`:name`) parameters, not positional `?`, because the
        WHERE clause is assembled dynamically from several optional pieces.
        """
        if sort_by not in _SORT_COLUMNS:
            raise ValueError(f"sort_by must be one of {sorted(_SORT_COLUMNS)}, got {sort_by!r}")
        if sort_dir not in ("asc", "desc"):
            raise ValueError(f"sort_dir must be 'asc' or 'desc', got {sort_dir!r}")

        params: dict[str, object] = {
            "profile_hash": profile_hash,
            "threshold": threshold,
            "page_size": page_size,
        }
        sort_col = _SORT_COLUMNS[sort_by]
        if sort_by == "posted_at":
            sort_expr = f"COALESCE({sort_col}, :null_sentinel)"
            params["null_sentinel"] = _NULL_SENTINELS[sort_dir]
        else:
            sort_expr = sort_col

        if only_status:
            status_clause = "COALESCE(s.status,'new') = :status"
            params["status"] = only_status
        else:
            status_clause = "COALESCE(s.status,'new') NOT IN ('dismissed', 'closed')"

        where = [
            "r.profile_hash = :profile_hash",
            "r.failed = 0",
            "r.score >= :threshold",
            "v.id NOT IN (SELECT vacancy_id FROM vacancy_duplicates)",
            status_clause,
        ]
        if after is not None:
            after_value, after_id = after
            op = "<" if sort_dir == "desc" else ">"
            where.append(
                f"({sort_expr} {op} :after_value "
                f"OR ({sort_expr} = :after_value AND v.id > :after_id))"
            )
            params["after_value"] = after_value
            params["after_id"] = after_id

        sql = f"""
            SELECT v.*, r.score, r.verdict, r.matched_skills, r.missing_skills,
                   r.hard_blockers, r.model, r.evidence,
                   COALESCE(s.status,'new') AS status,
                   {sort_expr} AS _sort_key
            FROM ratings r
            JOIN vacancies v ON v.id = r.vacancy_id
            LEFT JOIN vacancy_status s ON s.vacancy_id = v.id
            WHERE {" AND ".join(where)}
            ORDER BY {sort_expr} {sort_dir.upper()}, v.id ASC
            LIMIT :page_size
        """
        return list(self.conn.execute(sql, params))
```

```python
                   v1.title AS dup_title, v1.company AS dup_company,

            FROM vacancy_duplicates d
```

```python
"""Shared $EDITOR flow for pasting a full posting/description by hand.

Used by both the CLI (`update-description`, run interactively) and the TUI
(`e` in the vacancy list) -- the only difference between the two callers is
what happens to the terminal around the subprocess call, which each caller
owns itself (the TUI wraps this in `app.suspend()`; the CLI just calls it
directly, since it already owns the terminal).
"""

from __future__ import annotations

import os
import subprocess
import tempfile
from pathlib import Path


def open_in_editor(current: str, *, run=subprocess.run) -> str:
    """Write `current` to a tempfile, run $EDITOR on it, return the result.

    `run` is injectable so tests exercise this without shelling out to a
    real editor.
    """
    editor = os.environ.get("EDITOR", "vi")
    with tempfile.NamedTemporaryFile(mode="w", suffix=".txt", delete=False) as f:
        f.write(current)
        path = Path(f.name)
    try:
        run([editor, str(path)], check=True)
        return path.read_text(encoding="utf-8").strip()
    finally:
        path.unlink(missing_ok=True)
```

```python
def llm_hint(config: Config) -> str:
    """Backend-appropriate troubleshooting line for an LLMError.

    The three backends fail in different ways for different reasons, so a
    hint naming the wrong one (e.g. always suggesting `ollama serve` while
    JOBSEARCH_LLM=llamacpp) sends someone chasing the wrong server. Shared
    by the CLI and the TUI so both show the same guidance.
    """
    backend = config.llm_backend.lower()
    if backend == "ollama":
        return f"Is Ollama running? Try: ollama serve && ollama pull {config.ollama_model}"
    if backend == "llamacpp":
        return (
            f"Is llama-server running and reachable at {config.llamacpp_host}? "
            "If it's on another machine, check the port and that it's bound to "
            "0.0.0.0 rather than only 127.0.0.1."
        )
    if backend == "anthropic":
        return "Check ANTHROPIC_API_KEY is set and valid."
    return ""
```

```python
class JobsearchApp(App):
    """Browse, filter and act on rated vacancies without a display limit."""

    CSS = """
    #filterbar { height: 3; }
    #filterbar Input { width: 1fr; }
    #filterbar Select { width: 22; }
    """
    TITLE = "jobsearch"

    def __init__(self, *, config=None, store=None, candidate=None, llm=None) -> None:
        super().__init__()
        self._config = config or load_config()
        self.store = store or Store(self._config.db_path)

            yield Select(_SORT_OPTIONS, value="score", id="sort", allow_blank=False)
            yield Switch(id="remote-only")
            yield Static("remote only", id="remote-only-label")
        yield DataTable(id="table", cursor_type="row")
        yield Footer()
```

```python
    def mark_status_for_id(self, vacancy_id: str, status: str) -> None:
        self.store.set_status(vacancy_id, status)
        if vacancy_id in self._row_cache:
            self._row_cache[vacancy_id] = dict(self._row_cache[vacancy_id]) | {"status": status}

        still_in_view = (
            (self.view == "active" and status not in ("dismissed", "closed"))
            or (self.view not in ("active", "duplicates") and self.view == status)
        )
        table = self.query_one("#table", DataTable)
        if still_in_view:
            if vacancy_id in self._loaded_ids:
                table.update_cell(vacancy_id, self._columns[2], status)
        else:
            if vacancy_id in self._loaded_ids:
                table.remove_row(vacancy_id)
                self._loaded_ids.discard(vacancy_id)
```

```python
class DetailScreen(Screen):
    """Full detail for one vacancy -- the TUI equivalent of `_panel()` in
    cli/main.py's `show --full`."""

    BINDINGS = [
        ("escape", "close", "Back"),
        ("q", "close", "Back"),
        ("s", "mark_status('seen')", "Seen"),
        ("d", "mark_status('dismissed')", "Dismissed"),
        ("a", "mark_status('applied')", "Applied"),
    ]

    def __init__(self, row) -> None:
        super().__init__()
        self.row = row

    def compose(self) -> ComposeResult:
        yield Static(self._render(), id="detail-body")
        yield Footer()

    def _render(self) -> str:
        row = self.row
        matched = json.loads(row["matched_skills"] or "[]")
        missing = json.loads(row["missing_skills"] or "[]")
        blockers = json.loads(row["hard_blockers"] or "[]")
        penalty_notes = json.loads(row["evidence"] or "{}").get("penalty_notes") or []

        lines = [
            f"[bold]{row['score']}[/] · {row['title']}",
            f"[bold]{row['company']}[/] · {row['location_raw'] or 'location unspecified'}",
            f"[link={row['url']}]{row['url']}[/link]",
            f"status: {row['status']}",
            "",
        ]
        if matched:
            lines.append("[green]fits:[/]")
            for m in matched[:6]:
                lines.append(f"  + {m.get('skill', '')}")
                lines.append(f"    [dim]CV: “{m.get('evidence_cv', '')[:88]}”[/]")
                lines.append(f"    [dim]job: “{m.get('evidence_vacancy', '')[:88]}”[/]")
        if missing:
            lines.append(f"[yellow]missing:[/] {', '.join(missing[:8])}")
        if blockers:
            lines.append(f"[red]blockers:[/] {'; '.join(blockers[:4])}")
        if penalty_notes:
            lines.append("[dim]soft penalties:[/]")
            for note in penalty_notes:
                lines.append(f"  [dim]{rich_escape(note)}[/]")
        return "\n".join(lines)

    def action_close(self) -> None:
        self.app.pop_screen()

    def action_mark_status(self, status: str) -> None:
        self.app.mark_status_for_id(self.row["id"], status)
        self.app.pop_screen()
```

```python
"""Modal for the manual mark-duplicate escape hatch: dedupe.py's hash-based
identity misses near-duplicates (typo'd company, differently formatted
location, a snippet that differs across two sources' APIs for the same
role), so a human picks the pair here."""

from __future__ import annotations

from textual.app import ComposeResult
from textual.containers import Horizontal, Vertical
from textual.screen import ModalScreen
from textual.widgets import Button, Input, Label, ListItem, ListView, Static


class DuplicatePickerModal(ModalScreen[str | None]):
    """Search all vacancies and pick one as the canonical for `vacancy_id`.

    Dismisses with the chosen canonical_id, or None if cancelled -- the
    caller (JobsearchApp) does the actual `store.mark_duplicate` call and
    the resulting local table update; this modal only picks the target.
    """

    BINDINGS = [("escape", "cancel", "Cancel")]

    def __init__(self, store, vacancy_id: str, title: str, company: str) -> None:
        super().__init__()
        self.store = store
        self.vacancy_id = vacancy_id
        self._title, self._company = title, company
        self._results: list = []
        self._chosen = None

    def compose(self) -> ComposeResult:
        with Vertical(id="duplicate-modal"):
            yield Label(f"Mark “{self._title}” ({self._company}) as a duplicate of…")
            yield Input(placeholder="search title / company / id", id="dup-search")
            yield ListView(id="dup-results")
            yield Static("", id="dup-confirm")
            with Horizontal(id="dup-buttons"):
                yield Button("Confirm", id="dup-confirm-btn", disabled=True)
                yield Button("Cancel", id="dup-cancel-btn")

    def on_input_changed(self, event: Input.Changed) -> None:
        query = event.value.strip()
        results_view = self.query_one("#dup-results", ListView)
        results_view.clear()
        self._results = []
        self._set_chosen(None)
        if len(query) < 2:
            return
        for row in self.store.search_vacancies(query, limit=20):
            if row["id"] == self.vacancy_id:
                continue
            self._results.append(row)
            results_view.append(
                ListItem(Label(f"{row['title']} — {row['company']} [{row['id'][:8]}]"))
            )

    def on_list_view_selected(self, event: ListView.Selected) -> None:
        index = self.query_one("#dup-results", ListView).index
        if index is None or index >= len(self._results):
            return
        self._set_chosen(self._results[index])

    def _set_chosen(self, row) -> None:
        self._chosen = row
        confirm = self.query_one("#dup-confirm", Static)
        button = self.query_one("#dup-confirm-btn", Button)
        if row is None:
            confirm.update("")
            button.disabled = True
        else:
            confirm.update(f"Hide as a duplicate of “{row['title']}” ({row['company']})?")
            button.disabled = False

    def on_button_pressed(self, event: Button.Pressed) -> None:
        if event.button.id == "dup-confirm-btn" and self._chosen is not None:
            self.dismiss(self._chosen["id"])
        elif event.button.id == "dup-cancel-btn":
            self.dismiss(None)

    def action_cancel(self) -> None:
        self.dismiss(None)
```

```python
    def action_edit_description(self) -> None:
        if self.view == "duplicates" or self._selected_id is None:
            return
        self.edit_description_for_id(self._selected_id)

    def edit_description_for_id(self, vacancy_id: str) -> None:
        current = self.store.get_vacancy(vacancy_id)["description"] or ""
        new_text = self._prompt_editor(current)
        if not new_text or new_text == current:
            return
        self.store.update_description(vacancy_id, new_text)
        if vacancy_id in self._row_cache:
            self._row_cache[vacancy_id] = dict(self._row_cache[vacancy_id]) | {
                "description": new_text
            }
        self._rerate(vacancy_id)

    def _prompt_editor(self, current: str) -> str:
        """Isolated from edit_description_for_id so tests can monkeypatch
        just this method -- suspending the app to run a real subprocess
        editor is not something to exercise under `App.run_test()`'s
        headless driver, which is not guaranteed to support suspending."""
        with self.suspend():
            return open_in_editor(current)

    @work(thread=True)
    def _rerate(self, vacancy_id: str) -> None:
        llm = self._llm_override or build_llm(self._config)
        row = self.store.get_vacancy(vacancy_id)
        try:
            outcome = rate_and_save(self.store, self.candidate, llm, row, self.candidate.hash())
        except LLMError as exc:
            hint = llm_hint(self._config)
            message = f"{exc}\n{hint}" if hint else str(exc)
            self.call_from_thread(self.notify, message, severity="error")
            return
        if not outcome.ok:
            self.call_from_thread(self.notify, f"re-rate failed: {outcome.error}", severity="error")
            return
        self.call_from_thread(self._apply_rerate, vacancy_id, outcome.final_score)

    def _apply_rerate(self, vacancy_id: str, score: int) -> None:
        if vacancy_id in self._row_cache:
            self._row_cache[vacancy_id] = dict(self._row_cache[vacancy_id]) | {"score": score}
        if vacancy_id in self._loaded_ids and self.view != "duplicates":
            self.query_one("#table", DataTable).update_cell(vacancy_id, self._columns[0], str(score))
```

```markdown
`jobsearch tui` replaces `show`'s hard display limit with a keyset-paginated,
scrollable list -- keep scrolling (or reaching the bottom loads more

  blockers) -- the URL there is a clickable terminal hyperlink

- `c` cycles the view: active -> dismissed -> closed -> duplicates

- `e` opens $EDITOR on the description (same flow as `update-description`),
  then re-rates in the background without blocking the UI
- `r` refreshes, `q`/`Esc` goes back/quits

changes needed, a pseudo-TTY is allocated the same way any interactive
`docker compose run` already gets one.
```
