# Правила работы в проекте

## Docker Compose
- Команды проекта разрешено выполнять через `docker compose run --rm jobsearch <cmd>` (сервис одноразовый, не долгоживущий).

## База данных
- Удаление данных из базы (`jobsearch.db`) запрещено без явного разрешения пользователя.
- Перед любой операцией удаления/очистки данных — спросить разрешение.

## Bash-команды
- Разрешено выполнять любые безопасные bash-команды, относящиеся к этому проекту (сборка, тесты, линтеры, чтение файлов, docker compose и т.п.).
- Деструктивные/опасные команды (rm -rf, force-push, сброс состояния и т.п.) — только с разрешения пользователя.

## Git
- Разрешено делать `git commit` без дополнительного подтверждения.
- Push, force-push и другие операции, влияющие на удалённый репозиторий — только с разрешения пользователя.

## Поиск в интернете
- Разрешено гуглить (веб-поиск) для решения задач по проекту.
